# ✅ Todo App

A full-stack task management application with real-time CRUD operations, built with React, Node.js, Express, and MongoDB.

## 🔗 Live Demo
*(Coming soon — will be deployed on Vercel)*

## ✨ Features
- ➕ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as complete
- 💾 Persistent storage with MongoDB
- 📱 Responsive design

## 🛠️ Tech Stack

**Frontend:** React, CSS3

**Backend:** Node.js, Express.js, MongoDB Atlas, Mongoose
